# Projeto de cálculo de descontos em uma loja de acordo com o valor.
O projeto pedirá o valor total da compra, e de acordo com os dados recebidos, irá calcular o desconto.<br>
Valor < R$200 receberá um desconto de 5%.<br>
R$200 < Valor >R$300 receberá um desconto de 10%.<br>
Valor > R$300 receberá um desconto  de 15%.<br>
Após o processamento, o programa retornará em qual caso a compra se qualifica, indicando o desconto total e o novo valor a ser pago.
