# Projeto: Consumo mensal de água de acordo com o tipo de imóvel<div style="display: inline_block">
 <img align="center" alt="Python" height="40" width="40"

Este projeto foi feito em Python, com o ituito de praticar as estruturas de repeticao match e if.<br>
Ele servirá como uma classificacao do perfil de consumo dos imóveis dos moradores de uma região.<br>
Na **Entrada de dados**, é pedido informacoes sobre o imovel, como tipo e consumo mensal de água em m3.<br>
Caso o digitado pelo morador não seja compativel com o enunciado, o programa retornará com uma mensagem de erro <br>
Por precaução, o programa não diferencia as letras maisculas, na reposta do morador (como por exemplo:"Casa" e "casa").<br>
Por fim, o programa apresenta uma resposta de acordo com o tipo de imovel e o consumo, com uma mensagem dizendo se o consumo está baixo, mediano ou alto.
