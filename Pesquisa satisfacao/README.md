# ![Python](https://img.shields.io/badge/python-%233670A0.svg?style=plastic&logo=python&logoColor=ffdd54)<br>Projeto de pesquisa de satisfacao de uma empresa
O projeto pedirá o nome e a idade do clientes, e a sua satisfacao com essa empresa.<br>
A pesquisa será feita com 50 clientes.<br>
Ao acabar todas as respostas, indicará quantas respostas "Excelentes" ou "Ruins" tivemos no dia.<br>
O projeto tem como objetivo praticar a estrutura de repeticao "for" e "while"".
